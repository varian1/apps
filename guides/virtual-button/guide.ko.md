## 이 앱은 무엇을 하나요

Virtual Buttons는 휴대폰의 물리 버튼을 화면에 띄워 줍니다. 전원 버튼이나 볼륨 버튼이 고장 났거나 닳았거나 누르기 힘들다면, 화면의 버튼을 대신 누르세요. 뒤로가기, 홈, 최근 앱도 한 번의 터치로 사용할 수 있습니다.

- 전원 메뉴, 화면 잠금, 볼륨 높이기와 낮추기
- 버튼 두 개를 동시에 누르지 않고 스크린샷과 화면 녹화
- 홈, 뒤로가기, 최근 앱, 알림창, 빠른 설정
- 다른 앱 위에 뜨는 플로팅 버튼과 빠른 설정 타일

## 시작하기

1. **Virtual Buttons**를 엽니다.
2. **Setup** 아래에서 **Set up**이 표시된 카드를 누릅니다.
3. 열리는 안드로이드 화면에서 Virtual Buttons 접근성 서비스를 켭니다. 앱이 대신 버튼을 누르려면 이 서비스가 필요합니다.
4. 앱으로 돌아와 **Set up**이 표시된 다른 카드를 누릅니다.
5. Virtual Buttons가 다른 앱 위에 표시되도록 허용합니다. 플로팅 버튼에 필요한 설정입니다.
6. 두 카드 모두 **Enabled**로 바뀌었는지 확인합니다.

이 앱은 Android 9 이상에서 사용할 수 있습니다.

## 버튼 사용하기

1. **Buttons** 탭을 엽니다.
2. 필요한 버튼을 누릅니다. 예를 들어 **Lock screen**이나 **Volume up**을 누르세요.

사용할 수 있는 버튼은 **Power menu**, **Lock screen**, **Screenshot**, **Screen recording**, **Volume up**, **Volume down**, **Home**, **Back**, **Recent apps**, **Notifications**, **Quick Settings**입니다.

버튼이 작동하지 않으면 앱에 **Action unavailable**이 표시됩니다. **Setup** 아래 두 카드가 모두 **Enabled**인지 확인한 뒤 다시 시도하세요.

![버튼 모음이 보이는 Buttons 탭](shots/01-buttons.png)

## 화면 녹화하기

1. **Buttons** 탭을 엽니다.
2. **Screen recording**을 누릅니다.
3. 안드로이드가 화면 캡처 권한을 물으면 허용합니다.
4. 알림에서 녹화를 중지합니다.

영상은 휴대폰의 Movies 폴더에 저장됩니다. 소리는 녹음되지 않습니다.

## 플로팅 버튼 사용하기

1. **Floating button**을 켭니다.
2. 버블을 눌러 버튼 목록을 엽니다.
3. 버블을 화면 가장자리 어디로든 끌어서 옮깁니다.

스크린샷을 찍는 동안에는 버블이 숨겨지므로 사진에 나오지 않습니다.

![다른 앱 위에 표시된 플로팅 버블과 버튼 패널](shots/02-floating-button.png)

## 빠른 설정 타일 추가하기

1. 화면 맨 위에서 아래로 쓸어내려 빠른 설정을 엽니다.
2. 패널의 편집 모드를 엽니다.
3. Virtual Buttons의 잠금 화면 타일이나 스크린샷 타일을 패널로 끌어다 놓습니다.

## 플로팅 메뉴 꾸미기

이 기능은 프리미엄이 필요합니다.

1. **Customize** 탭을 엽니다.
2. 플로팅 메뉴에 표시할 버튼을 고르고 원하는 순서로 배치합니다.
3. 버블 크기, **Colour**, 투명도를 설정합니다.
4. 처음 배치로 되돌리려면 **Reset to standard**를 누릅니다.

![버블과 메뉴 옵션이 보이는 Customize 탭](shots/03-customize.png)

## 프리미엄

프리미엄을 구매하면 광고가 사라집니다. 또한 플로팅 메뉴의 버튼을 직접 고르고 순서를 바꿀 수 있으며, 버블의 크기, 색상, 투명도도 설정할 수 있습니다.

구독이 아니라 한 번만 결제하는 방식입니다.

1. **Premium & info** 탭을 엽니다.
2. **Get Premium**을 누릅니다.
3. 새 휴대폰에서는 **Restore purchase**를 눌러 프리미엄을 되찾으세요.

## 자주 묻는 질문

**전원 버튼이 고장 나도 사용할 수 있나요?**
네. **Lock screen**을 누르면 화면이 꺼지고, **Power menu**를 누르면 전원 끄기, 다시 시작, 긴급 전화를 할 수 있습니다.

**화면 녹화에 소리도 들어가나요?**
아니요. 화면 녹화는 영상만 저장됩니다.

**왜 접근성 서비스가 필요한가요?**
접근성 서비스는 누르신 버튼을 대신 실행하고 플로팅 버튼을 표시하는 데에만 사용합니다. 화면 내용이나 입력하는 글자를 읽지 않습니다.

**인터넷 연결이나 계정이 필요한가요?**
아니요. 버튼은 오프라인에서도 작동하고 계정도 필요 없습니다. 무료 버전에는 광고가 표시됩니다.

**아이폰에서도 사용할 수 있나요?**
아니요. Virtual Buttons는 안드로이드 전용입니다.

## 개인정보

Virtual Buttons에는 계정도 서버도 없으며, 설정과 녹화 영상은 휴대폰에만 저장됩니다. 무료 버전에는 Google AdMob 광고가 표시되며, Google AdMob은 기기 식별자, 대략적인 위치, 사용 데이터를 수집할 수 있습니다. **Premium & info**를 열고 **Privacy policy**를 누르면 전체 개인정보 처리방침을 볼 수 있고, **Ad privacy choices**를 누르면 광고 설정을 바꿀 수 있습니다.
