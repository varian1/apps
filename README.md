# App guides

How-to guides for our Android apps, with screenshots, and the website built from them.

- `guides/<slug>/guide.md`: the guide for one app. Edit these; see `GUIDE-FORMAT.md`.
- `guides/<slug>/shots/`: its screenshots.
- `site.json`: site title, tagline, support address and the order of the apps.
- `docs/`: the built website. Do not edit by hand; the Developer Tools dashboard rebuilds it from the guides.

The site is published with GitHub Pages from `docs/`.
