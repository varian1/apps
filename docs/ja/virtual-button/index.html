できること

Virtual Buttonsは、スマートフォンの物理ボタンを画面上に表示するアプリです。電源ボタンや音量ボタンが壊れたり、すり減ったり、押しにくかったりするときは、画面のボタンをタップして代わりに使えます。戻る、ホーム、最近使ったアプリもワンタップで操作できます。

  • 電源メニュー、画面ロック、音量を上げる・下げる
  • 2つのボタンを同時に押さずにスクリーンショットと画面録画
  • ホーム、戻る、最近使ったアプリ、通知、クイック設定
  • 他のアプリの上に表示されるフローティングボタンと、クイック設定タイル

はじめに

  1. Virtual Buttons を開きます。
  2. Setup の下で、Set up と表示されているカードをタップします。
  3. 開いたAndroidの画面で、Virtual Buttonsのユーザー補助サービスをオンにします。アプリがボタンを代わりに押すために必要です。
  4. アプリに戻り、Set up と表示されているもう1つのカードをタップします。
  5. 他のアプリの上にVirtual Buttonsを表示することを許可します。フローティングボタンに必要です。
  6. 2つのカードの表示がどちらも Enabled になったことを確認します。

Android 9以降が必要です。

ボタンを使う

  1. Buttons タブを開きます。
  2. 使いたいボタン(たとえば Lock screen や Volume up)をタップします。

使えるボタンは Power menu、Lock screen、Screenshot、Screen recording、Volume up、Volume down、Home、Back、Recent apps、Notifications、Quick Settings です。

ボタンが動作しない場合は、Action unavailable と表示されます。Setup の下の2つのカードがどちらも Enabled になっているか確認して、もう一度お試しください。

画面を録画する

  1. Buttons タブを開きます。
  2. Screen recording をタップします。
  3. Androidから確認が出たら、画面のキャプチャを許可します。
  4. 録画を止めるには、通知から停止します。

動画はスマートフォンのMoviesフォルダに保存されます。音声は録音されません。

フローティングボタンを使う

  1. Floating button をオンにします。
  2. 丸いボタンをタップすると、ボタンの一覧が開きます。
  3. 丸いボタンは、画面のどの端にでもドラッグして移動できます。

スクリーンショットを撮るときは丸いボタンが隠れるので、画像に写りません。

クイック設定タイルを追加する

  1. 画面の上から下にスワイプして、クイック設定を開きます。
  2. パネルの編集モードを開きます。
  3. Virtual Buttonsの Lock screen または Screenshot のタイルを、パネルにドラッグして追加します。

フローティングメニューをカスタマイズする

Premiumが必要です。

  1. Customize タブを開きます。
  2. フローティングメニューに表示するボタンを選び、好きな順番に並べ替えます。
  3. 丸いボタンのサイズ、Colour、透明度を設定します。
  4. 元のレイアウトに戻すには、Reset to standard をタップします。

Premium

Premiumにすると、広告が表示されなくなります。また、フローティングメニューのボタンを選んで並べ替えたり、丸いボタンのサイズ、色、透明度を設定したりできます。

支払いは買い切りで、サブスクリプションではありません。

  1. Premium & info タブを開きます。
  2. Get Premium をタップします。
  3. 新しいスマートフォンでPremiumを元に戻すには、Restore purchase をタップします。

よくある質問

電源ボタンが壊れていても使えますか? はい。画面を消すには Lock screen、電源を切る・再起動する・緊急通報をするには Power menu をタップします。

画面録画に音声は入りますか? いいえ。画面録画は映像のみです。

なぜユーザー補助サービスが必要ですか? タップしたボタンを押す動作と、フローティングボタンの表示にだけ使います。画面の内容や入力した文字を読み取ることはありません。

インターネット接続やアカウントは必要ですか? いいえ。ボタンはオフラインで使え、アカウントも不要です。無料版では広告が表示されます。

iPhoneでも使えますか? いいえ。Virtual ButtonsはAndroid専用です。

プライバシー

Virtual Buttonsにはアカウントもサーバーもなく、設定と録画データはお使いのスマートフォン内に保存されます。無料版ではGoogle AdMobの広告が表示され、端末識別子、おおよその位置情報、利用データが収集されることがあります。Premium & info を開き、Privacy policy をタップすると詳しいポリシーを読めます。広告の設定を変えるには Ad privacy choices をタップします。
