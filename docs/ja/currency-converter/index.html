What it does

Currency Converterは、ひとつの金額を保存した通貨すべてに一度に換算するアプリです。旅行者やネットショッピングをする人、さっと換算したい人に向いています。最後にダウンロードしたレートを保存しているので、通信できないときでも換算できます。

  • ひとつの金額を、複数の通貨に同時に換算できます。
  • 150以上の通貨を、名前またはコードで検索できます。
  • 内蔵の電卓で計算し、その結果をそのまま換算に使えます。
  • レートの取得元を選べます。ライトテーマとダークテーマに対応し、16の言語で使えます。

Get started

  1. 通信できる状態でアプリを開きます。最新のレートをダウンロードして、スマートフォンに保存します。
  2. 広告の同意を求められたら、選択してください。あとから Settings で変更できます。
  3. Convert タブを開いて、金額を入力します。

Convert an amount

  1. Convert タブを開きます。
  2. 金額を入力します。
  3. 保存した各通貨での結果を確認します。
  4. 別の通貨を基準に換算するには、その通貨をタップします。

レートの取得元、レートの日付、ダウンロードした日時は、いつでもアプリに表示されます。

Save your favourite currencies

  1. Convert タブから通貨の一覧を開きます。
  2. 通貨を名前またはコードで検索します。
  3. お気に入りに保存します。
  4. お気に入りを好きな順番に並べ替えます。

Use the calculator

  1. Calculator タブを開きます。
  2. 式を入力して計算します。足し算、引き算、掛け算、割り算のほか、かっこやパーセントも使えます。
  3. 結果を換算に送ります。

Choose a rate source

  1. Settings タブを開きます。
  2. 無料のレート取得元3つから、ひとつを選びます。
  3. 取得元をテストして、接続できるか確認します。

取得元によって、対応する通貨や更新のタイミングが異なります。多くは1日に1回更新されます。

Change the theme

  1. Settings タブを開きます。
  2. ライトまたはダークを選びます。スマートフォンの設定に合わせることもできます。

Questions

オフラインでも使えますか? はい。一度でもレートをダウンロードしていれば使えます。オフラインのときや、レートの取得元に接続できないときは、最後に保存したレートで換算します。

リアルタイムのレートですか? いいえ。参考レートで、多くの取得元は1日に1回更新されます。レートの日付が表示されるので、どのくらい新しいか確認できます。

銀行で案内される金額と違うのはなぜですか? 銀行、カード会社、海外送金サービス、両替所は、それぞれ独自のレートや手数料を使っています。アプリのレートは参考としてお使いください。

表示されない通貨があるのはなぜですか? レートの取得元によって対応する通貨が異なり、少ないものもあります。Settings で別の取得元を試してください。

暗号資産や金は表示されますか? いいえ。このアプリで扱うのは世界の通貨のみです。

Privacy

入力した金額と保存した通貨は、スマートフォンの中にだけ保存されます。アプリは、レートを取得するために、あなたが選んだレートの取得元に接続します。アプリは無料で、Google AdMob の広告を表示します。AdMob は、端末の識別子、おおよその位置情報、アプリの操作内容を収集することがあります。法律で必要とされる場合は、先に同意をお尋ねし、あとから Settings で変更できます。プライバシーポリシーはまだ公開されていません。
