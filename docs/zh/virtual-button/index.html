功能简介

Virtual Buttons 把手机的实体按键搬到屏幕上。如果你的电源键或音量键坏了、磨损了或不好按，直接点屏幕上的按键就行。你还可以一键使用返回、主页和最近任务。

  • 电源菜单、锁屏、音量加和音量减
  • 不用同时按两个键，就能截屏和录屏
  • 主页、返回、最近任务、通知栏和快捷设置
  • 悬浮在其他应用上方的悬浮球，以及快捷设置磁贴

开始使用

  1. 打开 Virtual Buttons。
  2. 在 Setup 下，点击显示 Set up 的卡片。
  3. 在弹出的安卓页面中，开启 Virtual Buttons 无障碍服务。应用需要它来替你按键。
  4. 返回应用，点击另一张显示 Set up 的卡片。
  5. 允许 Virtual Buttons 显示在其他应用上层。悬浮按钮需要这项权限。
  6. 确认两张卡片现在都显示 Enabled。

应用需要 Android 9 或更高版本。

使用按键

  1. 打开 Buttons 标签页。
  2. 点击你需要的按键，例如 Lock screen 或 Volume up。

可用的按键有：Power menu、Lock screen、Screenshot、Screen recording、Volume up、Volume down、Home、Back、Recent apps、Notifications 和 Quick Settings。

如果某个按键没有反应，应用会显示 Action unavailable。请检查 Setup 下的两张卡片是否都显示 Enabled，然后再试一次。

录制屏幕

  1. 打开 Buttons 标签页。
  2. 点击 Screen recording。
  3. 在安卓询问时，允许屏幕捕获。
  4. 在录屏通知中停止录制。

视频会保存在手机的 Movies 文件夹中，没有声音。

使用悬浮按钮

  1. 打开 Floating button。
  2. 点击悬浮球，展开你的按键。
  3. 把悬浮球拖到屏幕的任意一侧边缘。

截屏时悬浮球会自动隐藏，不会出现在截图里。

添加快捷设置磁贴

  1. 从屏幕顶部向下滑动，打开快捷设置。
  2. 进入面板的编辑模式。
  3. 把 Virtual Buttons 的锁屏或截屏磁贴拖到你的面板中。

自定义悬浮菜单

此功能需要 Premium。

  1. 打开 Customize 标签页。
  2. 选择要显示在悬浮菜单中的按键，并按你想要的顺序排列。
  3. 设置悬浮球的大小、Colour 和透明度。
  4. 点击 Reset to standard 可恢复为原来的布局。

Premium

Premium 可以去除广告。你还可以选择悬浮菜单中的按键并调整顺序，以及设置悬浮球的大小、颜色和透明度。

这是一次性购买，不是订阅。

  1. 打开 Premium & info 标签页。
  2. 点击 Get Premium。
  3. 换了新手机后，点击 Restore purchase 即可找回 Premium。

常见问题

电源键坏了还能用吗？ 可以。点击 Lock screen 关闭屏幕，或点击 Power menu 进行关机、重启或紧急呼叫。

录屏有声音吗？ 没有。录屏只有画面。

为什么应用需要无障碍服务？ 应用只用它来替你按下你点击的按键，并显示悬浮按钮。它不会读取你的屏幕内容或你输入的文字。

需要联网或注册账号吗？ 不需要。按键可离线使用，也没有账号。免费版会显示广告。

iPhone 能用吗？ 不能。Virtual Buttons 仅适用于安卓。

隐私

Virtual Buttons 没有账号和服务器，你的设置和录屏都保存在手机上。免费版会显示来自 Google AdMob 的广告，AdMob 可能会收集设备标识符、大致位置和使用数据。打开 Premium & info，点击 Privacy policy 可阅读完整的隐私政策，点击 Ad privacy choices 可更改广告设置。
