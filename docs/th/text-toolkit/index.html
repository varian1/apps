What it does

Text Toolkit คือแอปหน้าจอเดียวที่รวมเครื่องมือจัดการข้อความไว้เก้าอย่าง พิมพ์หรือวางข้อความในช่องด้านบน เลือกเครื่องมือ แล้วคัดลอกหรือแชร์ผลลัพธ์ได้ทันที แอปนับคำ เปลี่ยนตัวพิมพ์ใหญ่เล็ก ล้างช่องว่าง เรียงบรรทัด ค้นหาและแทนที่ กลับข้อความ เข้ารหัส จัดรูปแบบ JSON และเทียบข้อความสองชุด

  • ทุกเครื่องมือทำงานบนเครื่องของคุณและใช้ได้โดยไม่ต้องต่ออินเทอร์เน็ต
  • ไม่ต้องสมัครบัญชี ข้อความของคุณจะไม่ถูกอัปโหลด และแอปไม่ใช้กล้อง รูปภาพ รายชื่อติดต่อ หรือตำแหน่งที่ตั้ง
  • แอปไม่บันทึกข้อความของคุณ ข้อความจะหายไปเมื่อปิดแอป
  • ใช้ฟรี อาจมีแบนเนอร์โฆษณาที่ด้านล่างของหน้าจอ

Get started

  1. เปิด Text Toolkit ช่อง YOUR TEXT มีข้อความตัวอย่างสั้น ๆ ให้ลองใช้แต่ละเครื่องมือ
  2. แตะ Clear แล้วพิมพ์ข้อความของคุณเอง หรือแตะ Paste เพื่อแทนที่ด้วยข้อความที่คัดลอกมาจากแอปอื่น แตะ Sample เพื่อเรียกข้อความตัวอย่างกลับมา
  3. เลือกเครื่องมือในแถวใต้ช่องข้อความ: Counter, Case, Clean, Lines, Replace, Reverse, Encode, Format หรือ Diff ปัดแถวไปทางข้างเพื่อดูให้ครบ

แอปใช้ภาษาตามที่ตั้งไว้ในโทรศัพท์ของคุณ รองรับ 11 ภาษา ได้แก่ อังกฤษ สเปน โปรตุเกส เยอรมัน ฝรั่งเศส ฮินดี อินโดนีเซีย อาหรับ อิตาลี รัสเซีย และตุรกี

Count words and characters

  1. แตะ Counter
  2. ดูตัวเลขที่แสดง: Characters, No spaces, Words, Sentences, Paragraphs, Lines และ Reading time
  3. ดู TOP WORDS ด้านล่างเพื่อดูคำที่คุณใช้บ่อยที่สุด สูงสุดแปดคำ พร้อมจำนวนครั้งของแต่ละคำ

ตัวเลขจะเปลี่ยนไปตามที่คุณพิมพ์ เวลาอ่านคำนวณจาก 200 คำต่อนาที

Change the letter case

  1. แตะ Case
  2. เลื่อนดูการ์ด แต่ละใบแสดงข้อความของคุณในรูปแบบต่างกัน: UPPERCASE, lowercase, Title Case, Sentence case, Capitalized Case, aLtErNaTiNg, iNVERSE, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE และ URL slug
  3. แตะ Copy บนการ์ดที่ต้องการ

Clean up text

  1. แตะ Clean
  2. แตะหนึ่งในการทำงานเหล่านี้:
    • Clean all: ลบแท็บ ช่องว่างซ้ำ ช่องว่างท้ายบรรทัด บรรทัดว่าง และบรรทัดซ้ำในครั้งเดียว
    • Extra spaces, Trim lines, No empty lines, No duplicates หรือ Remove tabs: ทำเพียงอย่างเดียวตามชื่อปุ่ม
    • ปุ่มลบการขึ้นบรรทัดใหม่: ลบการขึ้นบรรทัดใหม่ออกจากข้อความของคุณ
  3. ดูผลลัพธ์ใต้ CLEANED RESULT ข้อความของคุณในช่องจะยังเหมือนเดิม

Sort or reverse

  1. แตะ Lines เพื่อจัดการทั้งบรรทัด: A to Z, Z to A, Reverse lines, Shortest first, No duplicates หรือ Reverse characters การเรียงลำดับจะไม่สนใจตัวพิมพ์ใหญ่และช่องว่างที่ต้นบรรทัด
  2. แตะ Reverse เพื่อกลับข้อความ: Entire text, Each word, Word order, Line order หรือ Characters per line
  3. ผลลัพธ์จะแสดงในการ์ดใต้ปุ่ม

Find and replace

  1. แตะ Replace
  2. พิมพ์ข้อความที่ต้องการค้นหาใน Find และข้อความใหม่ใน Replace with
  3. แตะตัวเลือกเพื่อเปิดหรือปิด: Replace all (ถ้าปิดจะเปลี่ยนเฉพาะที่พบรายการแรก), Case sensitive และ Whole word
  4. ตรวจจำนวนที่แทนที่และ REPLACEMENT PREVIEW ทั้งสองอย่างจะอัปเดตตามที่คุณพิมพ์

การค้นหาจะหาตรงตามที่คุณพิมพ์ทุกตัวอักษร ไม่รองรับรูปแบบพิเศษหรืออักขระแทน

Encode, decode and format

  1. แตะ Encode เลือก URL, Base64 หรือ HTML Entities แล้วแตะ Encode หรือ Decode
  2. แตะ Format แล้วเลือก Format JSON เพื่อย่อหน้า JSON ด้วยสองช่องว่าง, Minify JSON เพื่อรวมเป็นบรรทัดเดียว หรือ Strip Markdown เพื่อแปลง Markdown เป็นข้อความธรรมดา
  3. ถ้า JSON มีข้อผิดพลาด บรรทัดใกล้ด้านบนของหน้าจอจะขึ้นต้นด้วย "Invalid JSON" และบอกว่าผิดตรงไหน

Compare two texts

  1. ใส่ข้อความฉบับแรกใน YOUR TEXT แล้วแตะ Diff
  2. พิมพ์หรือวางข้อความฉบับที่สองใน COMPARE WITH
  3. ดู DIFF COMPARISON บรรทัดที่มีเฉพาะในฉบับที่สองเป็นสีเขียวและมี + บรรทัดที่มีเฉพาะในฉบับแรกเป็นสีแดงและมี - บรรทัดที่ตรงกันจะไม่มีเครื่องหมาย
  4. แตะ Copy Diff เพื่อคัดลอกผลการเทียบพร้อมเครื่องหมาย + และ -

Copy, share or keep working

  1. แตะ Copy บนการ์ดผลลัพธ์เพื่อคัดลอกไปที่คลิปบอร์ด
  2. แตะ Share เพื่อส่งไปยังแอปอื่น
  3. แตะ Use input เพื่อย้ายผลลัพธ์ไปที่ YOUR TEXT แล้วใช้เครื่องมืออื่นต่อได้

Premium

ทุกเครื่องมือใช้ได้ฟรี มีการซื้อแบบจ่ายครั้งเดียวที่เลือกซื้อหรือไม่ก็ได้ เพื่อนำโฆษณาออก คุณจ่ายเพียงครั้งเดียว ไม่ใช่การสมัครสมาชิก

Questions

ใช้ออฟไลน์ได้ไหม ได้ ทั้งเก้าเครื่องมือทำงานบนโทรศัพท์ของคุณ เฉพาะโฆษณาและการซื้อเพื่อนำโฆษณาออกเท่านั้นที่ต้องใช้อินเทอร์เน็ต

แอปบันทึกข้อความของฉันไหม ไม่บันทึก แอปเก็บข้อความไว้เฉพาะตอนที่เปิดแอปอยู่ หากต้องการเก็บผลลัพธ์ไว้ ให้คัดลอกหรือแชร์ออกไป

ทำไมผลลัพธ์ว่างเปล่าหลังเปลี่ยนเครื่องมือ Clean, Lines, Reverse, Encode และ Format ใช้การ์ดผลลัพธ์ใบเดียวกัน และจะถูกล้างเมื่อคุณเปลี่ยนเครื่องมือ ให้แตะการทำงานนั้นอีกครั้ง ทำเช่นเดียวกันหลังแก้ไขข้อความ ส่วน Counter, Case, Replace และ Diff จะอัปเดตเอง

รองรับโหมดมืดไหม รองรับ แอปใช้ธีมสว่างหรือมืดตามที่ตั้งไว้ในโทรศัพท์ของคุณ

ดูใบอนุญาตได้ที่ไหน เลื่อนลงไปด้านล่างสุดแล้วแตะ Open-source licenses ส่วน Privacy policy อยู่ข้าง ๆ

Privacy

ข้อความของคุณถูกประมวลผลบนโทรศัพท์ และจะไม่ถูกอัปโหลดหรือบันทึก แอปอาจแสดงโฆษณาจาก Google AdMob หากกฎหมายกำหนด แอปจะถามตัวเลือกของคุณก่อน และคุณเปลี่ยนได้ที่ Ad privacy choices บนหน้าจอหลัก อ่านนโยบายความเป็นส่วนตัวฉบับเต็มได้ที่นี่
