Steady ทำอะไรได้บ้าง

Steady คือแอปติดตามนิสัยที่ใช้งานสบาย คุณเลือกได้ว่าแต่ละนิสัยต้องทำวันไหน เช็กอินด้วยการแตะครั้งเดียว แล้วดูสตรีคของคุณเพิ่มขึ้นเรื่อย ๆ แอปนี้เป็นเครื่องมือช่วยสร้างกิจวัตรเพื่อสุขภาพที่ดี ไม่ใช่แอปทางการแพทย์

  • ไม่ต้องมีบัญชี และไม่มีการซิงก์ขึ้นคลาวด์ นิสัยและการเช็กอินของคุณเก็บอยู่ในโทรศัพท์
  • สตรีคนับเฉพาะวันที่คุณกำหนดไว้ ดังนั้นวันหยุดที่วางแผนไว้จะไม่ทำให้สตรีคขาด
  • ตั้งการแจ้งเตือนในเครื่องได้ตามต้องการ
  • ใช้ฟรีได้สูงสุด 3 นิสัย Premium เพิ่มจำนวนนิสัยไม่จำกัด ประวัติย้อนหลังครบ สถิติและสีเพิ่มเติม และไม่มีโฆษณา

เริ่มต้นใช้งาน

  1. เปิด Steady แท็บ Today จะแสดงข้อความ "Start your first habit"
  2. แตะ Create a habit
  3. พิมพ์ชื่อ แล้วแตะ Save นิสัยจะต้องทำทุกวัน เว้นแต่คุณจะเปลี่ยนตารางวัน

Steady จะขอสิทธิ์ส่งการแจ้งเตือนก็ต่อเมื่อคุณเปิดการเตือนเท่านั้น

สร้างนิสัยใหม่

  1. ในแท็บ Today แตะปุ่ม + ที่มุมขวาบน
  2. ที่ช่อง Name พิมพ์สิ่งที่คุณอยากทำ ได้ไม่เกิน 40 ตัวอักษร
  3. เลือก Icon และ Color
  4. ที่ Schedule แตะ Daily, Weekdays หรือ Weekends หรือแตะเลือกเป็นรายวันเพื่อเปิดหรือปิดวันนั้น ต้องเปิดไว้อย่างน้อยหนึ่งวัน
  5. แตะ Save หากไม่ต้องการบันทึก แตะ Cancel เพื่อออก

เช็กอิน

  1. เปิดแท็บ Today นิสัยที่ต้องทำวันนี้จะอยู่ใต้ Due today
  2. แตะปุ่มกลมข้างนิสัยเพื่อทำเครื่องหมายว่าทำแล้ว แตะอีกครั้งเพื่อยกเลิก
  3. ดูการ์ดด้านบนนับเพิ่มขึ้น เช่น "2 of 3 done" จนขึ้นว่า "All done for today"

สตรีคของคุณแสดงอยู่ใต้ชื่อนิสัยแต่ละอย่าง นิสัยที่ไม่ต้องทำวันนี้จะอยู่ใต้ Not due today พร้อมวันที่กำหนด

ตั้งการแจ้งเตือน

  1. เปิดนิสัยที่ต้องการ แตะ Edit แล้วเลื่อนไปที่ Reminder คุณตั้งค่านี้ตอนสร้างนิสัยใหม่ก็ได้
  2. เปิด Daily reminder และอนุญาตการแจ้งเตือนหากระบบ Android ถาม
  3. ตั้งเวลา: ปุ่มลบและบวกจะเลื่อนครั้งละหนึ่งชั่วโมง ส่วน −5 min และ +5 min จะเลื่อนครั้งละห้านาที หรือแตะเลือกหนึ่งในสี่เวลาที่ตั้งไว้ให้
  4. แตะ Save

การเตือนจะส่งเป็นการแจ้งเตือนในวันที่นิสัยนั้นกำหนดไว้ หากปิดการแจ้งเตือนของ Steady ไว้ ฟอร์มจะบอกให้ทราบและแสดงปุ่ม Open Settings

ดูสตรีคและประวัติ

  1. แตะนิสัยในแท็บ Today หรือ Stats
  2. ดู Current streak, Longest streak และ Last 30 days
  3. ใต้ History ดูปฏิทินของเดือนนั้น วัน Done, Missed และ Upcoming จะมีเครื่องหมายแสดงไว้ ใช้ลูกศรเพื่อเปลี่ยนเดือน
  4. หากลืมเช็กอิน แตะวันที่ผ่านมาที่กำหนดไว้เพื่อทำเครื่องหมายว่าทำแล้ว หรือแตะอีกครั้งเพื่อยกเลิก

เวอร์ชันฟรีแสดงเดือนนี้และเดือนที่แล้ว

ดูสถิติ

  1. แตะแท็บ Stats
  2. Last 7 days และ Last 30 days แสดงเป็นเปอร์เซ็นต์ว่าคุณเช็กอินตามที่กำหนดได้กี่ครั้ง
  3. ใต้ Streaks แต่ละนิสัยจะแสดงสตรีคปัจจุบันและสตรีคที่ดีที่สุด แตะนิสัยเพื่อเปิดดู

แก้ไข เก็บถาวร หรือลบนิสัย

  1. แตะนิสัย แล้วแตะ Edit เพื่อเปลี่ยนชื่อ ไอคอน สี ตารางวัน หรือการเตือน จากนั้นแตะ Save
  2. แตะ Archive habit เพื่อซ่อนนิสัยจาก Today และ Stats โดยยังเก็บการเช็กอินไว้ หากต้องการนำกลับมา เปิด Settings แล้วแตะ Restore ใต้ Archived habits
  3. แตะ Delete habit เพื่อลบนิสัยและการเช็กอินทั้งหมดอย่างถาวร ไม่สามารถย้อนกลับได้

เปลี่ยนสีและตั้งค่า

  1. แตะแท็บ Settings
  2. ใต้ Appearance แตะเลือกสีหลัก สี Ocean และ Forest ใช้ได้ฟรี
  3. ใต้ Privacy คุณเปิด Do not sell or share my personal information ได้
  4. Version อยู่ด้านล่างสุด ใต้ About

Steady ใช้ธีมสว่างหรือมืดตามที่ตั้งไว้ในโทรศัพท์ของคุณ

Premium

Steady Premium ซื้อได้ภายในแอปผ่านบัญชีสโตร์ของคุณ เปิด Settings แล้วแตะ Upgrade เพื่อดูแพ็กเกจและราคาก่อนชำระเงิน Premium ให้คุณได้ดังนี้

  • นิสัยไม่จำกัดจำนวน เวอร์ชันฟรีมีได้ 3 นิสัย
  • ประวัติย้อนหลังครบทั้งหมด และ Advanced stats: อัตราความสำเร็จตามวันในสัปดาห์ และนิสัยที่ทำได้สม่ำเสมอที่สุดหรือที่ควรใส่ใจ
  • สีหลักทุกสี
  • Export data: ไฟล์ JSON ที่รวมนิสัยและการเช็กอินทั้งหมด บันทึกลงโฟลเดอร์ที่คุณเลือก
  • ไม่มีโฆษณา ผู้ใช้เวอร์ชันฟรีอาจเห็นแบนเนอร์เล็กหนึ่งแห่งในหน้า Stats

หากเคยซื้อ Premium แล้ว แตะ Restore purchases ใน Settings

คำถามที่พบบ่อย

ต้องมีบัญชีไหม ไม่ต้อง ไม่มีการสมัครสมาชิกและไม่มีการซิงก์ขึ้นคลาวด์ นิสัยของคุณอยู่ในโทรศัพท์

วันหยุดทำให้สตรีคขาดไหม ไม่ขาด สตรีคนับเฉพาะวันที่กำหนดไว้ และวันนี้จะยังไม่ทำให้สตรีคขาดจนกว่าวันจะสิ้นสุด

เมื่อวานลืมเช็กอิน แก้ได้ไหม ได้ เปิดนิสัยนั้นแล้วแตะวันที่ใต้ History

ถ้าถอนการติดตั้งแอปจะเกิดอะไรขึ้น นิสัยของคุณเก็บอยู่ภายในแอปในโทรศัพท์ จึงถูกลบไปพร้อมกับแอป Premium ช่วยส่งออกสำเนาไว้ก่อนได้

Steady เป็นแอปทางการแพทย์หรือเปล่า ไม่ใช่ แอปนี้ช่วยให้คุณสร้างกิจวัตร ไม่ได้วัด วินิจฉัย หรือรักษาภาวะสุขภาพใด ๆ

ความเป็นส่วนตัว

นิสัยและการเช็กอินของคุณเก็บอยู่ในโทรศัพท์ ไม่มีบัญชีและไม่มีการซิงก์ขึ้นคลาวด์ และ Steady ไม่ส่งข้อมูลนิสัยของคุณไปยังเซิร์ฟเวอร์ใด ๆ เวอร์ชันฟรีอาจแสดงโฆษณา คุณตรวจสอบตัวเลือกโฆษณาได้ที่ Privacy ใน Settings
