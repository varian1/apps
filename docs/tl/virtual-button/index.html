Ano ang magagawa nito

Inilalagay ng Virtual Buttons ang mga button ng phone mo sa screen. Kung sira, sira-sira na o mahirap pindutin ang power o volume button mo, i-tap na lang ang button sa screen. May Back, Home at Recent apps din na isang tap lang.

  • Power menu, lock screen, volume up at volume down
  • Screenshot at screen recording nang hindi pinipindot ang dalawang button
  • Home, Back, Recent apps, notifications at Quick Settings
  • Lumulutang na bubble sa ibabaw ng ibang app, at mga tile sa Quick Settings

Para makapagsimula

  1. Buksan ang Virtual Buttons.
  2. Sa ilalim ng Setup, mag-tap ng card na may Set up.
  3. I-on ang Accessibility service ng Virtual Buttons sa screen ng Android na magbubukas. Kailangan ito ng app para pindutin ang mga button para sa iyo.
  4. Bumalik sa app at i-tap ang isa pang card na may Set up.
  5. Payagan ang Virtual Buttons na lumabas sa ibabaw ng ibang app. Kailangan ito ng lumulutang na button.
  6. Tiyaking Enabled na ang dalawang card.

Kailangan ng app ang Android 9 o mas bago.

Gumamit ng button

  1. Buksan ang tab na Buttons.
  2. I-tap ang button na kailangan mo, halimbawa ang Lock screen o Volume up.

Ang mga button ay Power menu, Lock screen, Screenshot, Screen recording, Volume up, Volume down, Home, Back, Recent apps, Notifications at Quick Settings.

Kung hindi gumana ang isang button, lalabas sa app ang Action unavailable. Tiyaking Enabled ang dalawang card sa ilalim ng Setup, at subukan ulit.

I-record ang screen mo

  1. Buksan ang tab na Buttons.
  2. I-tap ang Screen recording.
  3. Payagan ang screen capture kapag nagtanong ang Android.
  4. Itigil ang recording mula sa notification nito.

Sine-save ang video sa Movies folder ng phone mo. Walang tunog ito.

Gamitin ang lumulutang na button

  1. I-on ang Floating button.
  2. I-tap ang bubble para buksan ang mga button mo.
  3. I-drag ang bubble sa kahit anong gilid ng screen.

Nagtatago ang bubble habang kumukuha ng screenshot, kaya wala ito sa larawan.

Magdagdag ng Quick Settings tiles

  1. Mag-swipe pababa mula sa itaas ng screen para buksan ang Quick Settings.
  2. Buksan ang edit mode ng panel.
  3. I-drag ang Lock screen o Screenshot tile ng Virtual Buttons papunta sa panel mo.

I-customize ang lumulutang na menu

Kailangan dito ang Premium.

  1. Buksan ang tab na Customize.
  2. Piliin kung aling mga button ang lalabas sa lumulutang na menu at ayusin ang pagkakasunod-sunod ayon sa gusto mo.
  3. Itakda ang laki ng bubble, Colour at transparency.
  4. I-tap ang Reset to standard para bumalik sa orihinal na ayos.

Premium

Inaalis ng Premium ang mga ad. Maaari mo ring piliin at ayusin ang pagkakasunod-sunod ng mga button sa lumulutang na menu, at itakda ang laki, kulay at transparency ng bubble.

Isang beses lang ang bayad, hindi ito subscription.

  1. Buksan ang tab na Premium & info.
  2. I-tap ang Get Premium.
  3. Sa bagong phone, i-tap ang Restore purchase para maibalik ang Premium mo.

Mga tanong

Magagamit ko ba ito kung sira ang power button ko? Oo. I-tap ang Lock screen para patayin ang screen, o ang Power menu para mag-power off, mag-restart o tumawag sa emergency.

May tunog ba ang mga screen recording? Wala. Video lang ang mga screen recording.

Bakit kailangan ng app ang Accessibility service? Ginagamit lang nito iyon para pindutin ang mga button na tina-tap mo at para ipakita ang lumulutang na button. Hindi nito binabasa ang screen mo o ang tina-type mo.

Kailangan ba ng internet o account? Hindi. Gumagana ang mga button kahit offline at walang account. May mga ad ang libreng bersyon.

Gumagana ba ito sa iPhone? Hindi. Para sa Android lang ang Virtual Buttons.

Privacy

Walang account at walang server ang Virtual Buttons, at nasa phone mo lang ang mga setting at recording mo. Nagpapakita ang libreng bersyon ng mga ad mula sa Google AdMob, na maaaring mangolekta ng mga device identifier, tinatayang lokasyon at data ng paggamit. Buksan ang Premium & info at i-tap ang Privacy policy para basahin ang buong patakaran, o ang Ad privacy choices para baguhin ang mga setting mo sa ad.
